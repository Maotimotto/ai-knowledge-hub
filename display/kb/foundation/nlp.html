认识RNN模型

概述

RNN，Recurrent Neutral Network，循环神经网络，它一般以序列数据作为输入，通过网络内部的结构设计有效捕捉序列之间的关系特征，一般也是以序列形式进行输出。

RNN的循环机制，就是让上一层的输出，能够作为当下输入的一部分。

作用

因为RNN结构能够很好利用序列之间的关系，因此针对自然界具有连续性的输入序列。如人类的语言，语音等进行很好的处理，广泛应用于NLP领域的各项任务，如文本分类，情感分析，意图识别，机器翻译等。RNN后来被Transformer架构所取代。

分类

我们从2个角度来分类：输入和输出结构、内部构造。

  • 输入和输出结构
  • N vs N - RNN
  • 输入序列和输出序列是等长的
  • 使用范围较小，比如用于生成诗句
  • N vs 1 - RNN
  • 输入是序列，输出是单值
  • 经常用于文本分类问题上
  • 1 vs N - RNN
  • 输入是单值，输出是序列。
  • 用于图片生成文字等
  • N vs M - RNN
  • 不限制输入输出长度的RNN
  • 由编码器和解码器组成，两者的内部结构都是某RNN，也被称为seq2seq架构
  • 最早提出用于机器翻译，现在还能用于阅读理解，文本摘要等
  • 内部构造
  • 传统RNN
  • LSTM
  • Bi-LSTM
  • GRU
  • Bi-GRU

传统RNN内部结构

内部结构分析：

shell
我们把目光集中在中间的方块部分，它的输入有两部分，分别是h(t-1)以及x(t)，代表上一时间步的隐层输出，以及此时间步的输入，它们进入RNN结构体后，会"融合"到一起，这种融合我们根据结构解释可知，是将二者进行拼接，形成新的张量[x(t), h(t-1)]，之后这个新的张量将通过一个全连接层(线性层)，该层使用tanh作为激活函数，最终得到该时间步的输出h(t)，它将作为下一个时间步的输入和x(t+1)一起进入结构体，以此类推。

一条样本，该样本只有一个token，隐藏层为一层的情况。

import torch
from torch import nn


def use1rnn():
    # input_size:输入层数据的维度，也就是多少个特征
    # hidden_size:隐藏层的特征
    # num_layers:隐藏层的数量，默认是1

    # sequence_length: 输入的序列长度
    # batch_size: 批次的样本数量
    # input_size：数据的维度
    input = torch.randn(1, 1, 5)

    # num_layer：隐藏层数
    # batch_size：批次的样本数
    # hidden_size：隐藏层的维度
    h0 = torch.zeros(1, 1, 6)

    output, hn = rnn(input,h0)
    print(output)
    print(output.size())
    print(output.shape)
    print(hn)




if __name__ == '__main__':
    use1rnn()

RNN的优缺点

优点：

  • 结构简单
  • 对计算资源要求低
  • 在短序列任务上性能和效果都表现优异

缺点：

  • 传统RNN在解决长序列之间的关联时，通过实践，证明经典RNN表现很差
  • 原因是在进行反向传播的时候，过长的序列导致梯度的计算异常，发生梯度消失或爆炸
  • 如果在训练过程中发生了梯度消失，权重无法被更新，最终导致训练失败
  • 梯度爆炸所带来的梯度过大，大幅度更新网络参数，在极端情况下，结果会溢出（NaN值）

LSTM模型

概述

LSTM，Long Short Term Memory，长短时记忆结构，是传统RNN的变体。与经典RNN相比，能够有效捕捉长序列之间的语义关联，缓解梯度消失或爆炸现象。

LSTM的结构非常复杂，核心结构可以分为四部分：

  • 遗忘门
  • 输入门
  • 细胞状态
  • 输出门

LSTM内部结构

  • 遗忘门

!1740891728772

shell
与传统RNN的内部结构计算非常相似，首先将当前时间步输入x(t)与上一个时间步隐含状态h(t-1)拼接，得到[x(t), h(t-1)]，然后通过一个全连接层做变换，最后通过sigmoid函数进行激活得到f(t)，我们可以将f(t)看作是门值，好比一扇门开合的大小程度，门值都将作用在通过该扇门的张量，遗忘门门值将作用的上一层的细胞状态上，代表遗忘过去的多少信息又因为遗忘门门值是由x(t), h(t-1)计算得来的，因此整个公式意味着根据当前时间步输入和上一个时间步隐含状态h(t-1)来决定遗忘多少上一层的细胞状态所携带的过往信息。

用于帮助调节流经网络的值，sigmoid函数将值压缩在0和1之间。

释义：上一个时间步隐藏输出和数据端输入拼接一起，与权重参数进行矩阵运算，再把数据经过sigmoid变换到【0,1】区间。

结论：作用在上一个时间步的细胞状态之上，表示对上一个时间步信息遗忘多少。

  • 输入门

!1740891832641

shell
我们看到输入门的计算公式有两个，第一个就是产生输入门门值的公式，它和遗忘门公式几乎相同，区别只是在于它们之后要作用的目标上。这个公式意味着输入信息有多少需要进行过滤，输入门的第二个公式是与传统RNN的内部结构计算相同，对于LSTM来讲，它得到的是当前的细胞状态，而不是像经典RNN一样得到的是隐含状态。

结论：输入门作用在当前时间步输入上，表示对当前时间步输入要使用多少。

  • 细胞状态

!1740891877702

shell
细胞更新的结构与计算公式非常容易理解，这里没有全连接层，只是将刚刚得到的遗忘门门值与上一个时间步得到的C(t-1)相乘，再加上输入门门值与当前时间步得到的未更新C(t)相乘的结果。最终得到更新后的C(t)作为下一个时间步输入的一部分，整个细胞状态更新过程就是对遗忘门和输入门的应用。

结论：遗忘门作用在上一个时间步细胞状态之上 。输入门作用在当前时间步的输入上，更新细胞状态。

  • 输出门

!1740891950105

shell
输出门部分的公式也是两个，第一个即是计算输出门的门值，它和遗忘门，输入门计算方式相同。第二个即是使用这个门值产生隐含状态h(t)，他将作用在更新后的细胞状态C(t)上，并做tanh激活，最终得到h(t)作为下一时间步输入的一部分。整个输出门的过程，就是为了产生隐含状态h(t)。

结论：输出门才是得到当前output输出的结果。

Bi-LSTM概述

Bi-LSTM，即双向的LSTM，它没有改变LSTM本身任何内部结构，只是将LSTM应用两次，且方向标不同，再将两次得到的LSTM结果进行拼接作为最终输出。

PyTorch构建LSTM

python
import torch.nn as nn
import torch

def use1lstm():
    # 模型：lstm
    # input_size：输入数据的特征维度
    # hidden_size：隐藏层的特征维度
    # num_layer：隐藏层的数量
    lstm = nn.LSTM(input_size=5, hidden_size=6, num_layers=1)

    # 输入的数据：input
    # sequence_length：数据的长度
    # batch_size：批次的样本数
    # input_size：数据的维度
    input = torch.randn(1, 1, 5)

    # 初始值：h0和c0
    # num_layer：隐藏层数
    # batch_size：批次样本数
    # hidden_size：隐藏层维度
    h0 = torch.zeros(1, 1, 6)
    c0 = torch.zeros(1, 1, 6)

    output, (hn, cn) = lstm(input, (h0, c0))
    print(output)
    print(hn)
    print(cn)

if __name__ == '__main__':
    use1lstm()

LSTM优缺点

  • 优点

LSTM的门结构能够有效减缓长序列问题中可能出现的梯度消失或爆炸，虽然不能杜绝梯度消失或者爆炸现象，但在更长的序列问题上表现优于传统的RNN

  • 缺点

内部结构复杂，训练效率在同等算力下比RNN低下

GRU模型

概述

GRU，Gate Recurrent Unit，门控循环单元结构，它也是传统的RNN变体，同LSTM一样，能够有效捕捉长序列之间的语义关联，缓解梯度消失或爆炸现象，同时它的计算结构要比LSTM简单。它的核心可以分为两部分：

  • 更新门
  • 重置门

GRU内部结构

详细图：

!1740900400130

shell
和之前分析过的LSTM中的门控一样，首先计算更新门和重置门的门值，分别是z(t)和r(t)，计算方法就是使用X(t)与h(t-1)拼接进行线性变换，

再经过sigmoid激活。之后重置门门值作用在了h(t-1)上，代表控制上一时间步传来的信息有多少可以被利用。

接着就是使用这个重置后的h(t-1)进行基本的RNN计算，即与x(t)拼接进行线性变化，经过tanh激活，得到新的h(t)。

最后更新门的门值会作用在新的h(t)，而1-门值会作用在h(t-1)上，随后将两者的结果相加，得到最终的隐含状态输出h(t)，这个过程意味着更新门有能力保留之前的结果，当门值趋于1时，输出就是新的h(t)，而当门值趋于0时，输出就是上一时间步的h(t-1)。

结论：

（1）上一个时间步隐藏输出和数据端输入拼接在一起，与权重参数w进行矩阵运算，再吧数据经过sigmoid变换到【0,1】区间，形成重置门。

（2）zt * ht含义：对当前时间步要使用多少（记忆多少，依赖多少）。

（3）（1-zt）*h（t-1）含义：对上一个时间步要使用多少（记忆多少，依赖多少）。

（4）zt=0，完全使用上一个隐藏层信息；zt=1，完全使用本次隐藏层信息。

Bi-GRU概述

Bi-GRU与Bi-LSTM的逻辑相同，都是不改变其内部结构，而是将模型应用两次且方向不同，再将两次得到的GRU结果进行拼接作为最终输出。

PyTorch构建GRU

python

import torch

def use1gru():
    # 初始化模型
    # input_size:输入样本维度
    # hidden_size：隐藏层维度
    # num_layer：隐藏层数量
    gru = nn.GRU(input_size=5, hidden_size=6, num_layers=1)

    # 初始化数据：input
    # sequence_length：每一批次的长度，也就是数据量
    # batch_size：总共多少批次
    # input_size：和初始化模型相同
    input = torch.randn(1, 1, 5)

    # 初始化数据：h0
    # num_layer：隐藏层数量
    # batch_size：批次数量
    # hidden_size：隐藏层维度

    output, hn = gru(input,h0)
    print(output)

优缺点

  • 优点

GRU和LSTM作用相同，在捕捉长序列语义关联时，能有效抑制梯度消失或爆炸，效果都优于传统RNN且计算复杂度相比LSTM要小

  • 缺点

不能完全解决梯度消失或者爆炸的现象，且不能并行计算。当然所有的RNN及其变体模型都不能并行计算。正是因为如此，才有了后面的Transformer的诞生。

一、RNN的核心概念：什么是循环神经网络？

循环神经网络（Recurrent Neural Network，简称RNN）是一种专门用于处理序列数据的深度学习模型。与传统的前馈神经网络（如CNN、全连接网络）“输入输出相互独立”的特性不同，RNN通过引入“循环结构”，让模型能够捕捉序列中的时序依赖关系，即当前的输出不仅依赖于当前的输入，还依赖于之前的历史输入信息——这就像人类思考时会结合过往经验一样，RNN也具备了“记忆”能力。

核心本质：通过隐藏层状态的循环传递，实现对序列历史信息的累积与利用，突破传统神经网络“无记忆”的局限。

序列数据是RNN的核心处理对象，常见的序列数据包括：

  • 自然语言：句子（词的序列）、文本（句子的序列）；
  • 时序数据：股票价格（时间点的序列）、气象数据（日期的序列）；
  • 多媒体数据：语音（音频帧的序列）、视频（图像帧的序列）。

二、RNN的核心结构：循环机制如何实现“记忆”？

2.1 基本结构拆解

RNN的核心结构由“输入层、隐藏层、输出层”组成，关键创新在于隐藏层的循环连接。为了更清晰地理解循环机制，我们可以从“展开式”和“折叠式”两个角度分析：

  1. 折叠式结构：隐藏层会接收两个输入——当前时刻的输入数据和上一时刻隐藏层的输出状态（即“记忆信息”），经过计算后输出当前时刻的隐藏状态和预测结果，形成“输入→隐藏层（带循环）→输出”的闭环。
  1. 展开式结构：将循环结构按“时间步”展开（假设序列长度为T），则可得到T个串联的“子网络”，每个子网络对应一个时刻的计算。第t个时刻的子网络接收第t个输入和第t-1个时刻的隐藏状态，输出第t个时刻的隐藏状态和输出——这种展开方式能直观体现“历史信息逐时刻累积”的过程。

2.2 核心计算公式与符号定义

设序列共有T个时间步，各核心变量定义及计算逻辑如下：

符号 含义 维度说明
x 第t时刻的输入数据 （输入维度，1），如词向量维度为512，则为（512,1）
h 第t时刻的隐藏层状态（核心“记忆”） （隐藏层维度，1），如隐藏层有128个神经元，则为（128,1）
y 第t时刻的输出结果 （输出维度，1），如分类任务有10类，则为（10,1）
W 输入层到隐藏层的权重矩阵 （隐藏层维度，输入维度）
W 隐藏层到自身的循环权重矩阵 （隐藏层维度，隐藏层维度）
W 隐藏层到输出层的权重矩阵 （输出维度，隐藏层维度）
b 隐藏层、输出层的偏置项 （隐藏层维度，1）、（输出维度，1）

核心计算步骤（前向传播）：

  1. 隐藏层状态更新：结合当前输入和上一时刻记忆，公式为：

h = tanh(W·x + W·h + b)

注：tanh为激活函数，用于引入非线性并将状态值压缩到[-1,1]区间，防止梯度爆炸。

  1. 输出层计算：基于当前隐藏状态生成输出，公式为：

y = softmax(W·h + b)

注：softmax用于分类任务，若为回归任务可去掉。

三、RNN的核心作用：解决哪些实际问题？

RNN的“记忆能力”使其在序列数据相关任务中不可或缺，核心作用可按“输入输出序列长度匹配”分为三大类场景，覆盖NLP、时序分析、语音等多个领域：

3.1 场景1：一对一（序列分类）

任务特点：输入为一个完整序列（如一句话、一段文本），输出为一个固定结果（如类别标签）——需利用整个序列的信息做全局判断。

典型应用：

  • 文本情感分析：输入一句话“这部电影剧情紧凑，演员演技出色”，输出“正面情感”。RNN通过逐词累积语义信息，最终通过最后一个时刻的隐藏状态h判断整体情感。
  • 时序数据分类：输入一段心电图序列，输出“正常”或“异常”——RNN捕捉心率变化的时序规律，识别异常波动模式。

3.2 场景2：一对多（序列生成）

任务特点：输入为一个固定信息（如一个关键词、一张图片），输出为一个序列（如一句话、一段文本）——需基于初始信息逐步生成有逻辑的序列。

典型应用：

  • 文本生成：输入关键词“春天、花园”，输出诗句“春入花园花竞放，蜂蝶翩跹戏蕊香”。RNN以初始关键词为x₁，生成的第一个词作为h₁，再基于h₁生成第二个词，逐时刻迭代生成序列。
  • 图像描述生成：输入一张“小狗在草地上追球”的图片，先通过CNN提取图像特征作为初始输入x₀，再由RNN生成描述文本——需结合图像内容和语言语法的时序逻辑。

3.3 场景3：多对多（序列转换）

任务特点：输入为一个序列，输出为另一个长度相同或不同的序列——需逐时刻匹配输入输出的时序关系，或实现序列间的语义转换。

典型应用：

  • 机器翻译（Encoder-Decoder结构）：输入英文序列“I love China”，输出中文序列“我爱中国”。这是RNN的经典应用，由“Encoder编码器”（RNN）处理输入序列得到全局语义向量h，再由“Decoder解码器”（RNN）基于h逐词生成输出序列。
  • 时序预测：输入过去7天的气温序列[25℃,26℃,27℃,28℃,27℃,29℃,30℃]，输出未来3天的气温预测[31℃,30℃,29℃]——RNN捕捉气温的日变化规律（如昼夜温差、趋势延续性），基于历史序列预测未来。
  • 语音识别：输入一段语音音频帧序列（多维度时序数据），输出对应的文本序列——RNN将连续的音频信号转换为离散的文字，需匹配语音节奏与文本的时序对应关系。

四、RNN的局限性与改进方向

4.1 核心局限性：长序列依赖问题

标准RNN虽能处理序列数据，但在长序列（如超过20个时间步）中会出现“梯度消失或梯度爆炸”问题：在反向传播更新参数时，梯度需要通过循环权重W逐时刻传递，当序列过长时，梯度会因多次乘以W而趋近于0（梯度消失）或无穷大（梯度爆炸）——导致模型无法学习到长距离的历史信息（如一句话中开头和结尾的语义关联）。

4.2 经典改进模型

为解决长序列依赖问题，研究者提出了基于“门控机制”的改进模型，核心是通过“门”控制历史信息的累积与遗忘，最典型的有两种：

  • LSTM（长短期记忆网络）：引入“输入门、遗忘门、输出门”三个门结构，遗忘门决定丢弃哪些历史信息，输入门决定保留哪些当前信息，输出门决定输出哪些隐藏状态——从结构上解决了梯度消失问题，能有效捕捉长序列依赖（如文本中的上下文关联）。
  • GRU（门控循环单元）：简化LSTM的结构，将输入门和遗忘门合并为“更新门”，保留重置门——参数更少、训练速度更快，在很多场景下性能接近LSTM。

五、核心总结

1. 核心价值：RNN通过隐藏层循环结构赋予模型“记忆”能力，是处理序列数据的基础模型，为NLP、时序分析等领域提供核心技术支撑。

2. 关键机制：通过隐藏状态h的逐时刻传递，累积历史信息，核心公式为h = tanh(Wx + Wh + b)。

3. 适用场景：覆盖一对一（分类）、一对多（生成）、多对多（转换）三大类序列任务，需根据任务选择具体结构（如Encoder-Decoder）。

4. 改进核心：标准RNN存在长序列依赖问题，LSTM/GRU通过门控机制解决，是实际应用中的主流选择。

子词生成与Ngrams

FastText⽀持两种n-gram机制：

  • 字符级n-gram：分解词为子词（如<产、产品），添加<和>标记词边界，捕捉词内部结构，解决OOV（out of vocabulary）问题。
  • 词级n-gram（wordNgrams）：组合相邻词为短语（如这个_产品），增强上下文建模。

字符级n-gram（minn=2，maxn=4）

文本：“这个 产品 很棒”，以产品为例，启动子词：

~~~shell

'产品', '<产', '<产品', '<产品>', '产品>', '品>'

~~~

词级n-gram（wordNgrams=2 示例）

⽂本：“这个 产品 很棒”，启用wordNgrams=2：

~~~shell

1-gram：这个、产品、很棒

2-gram：这个、产品、很棒，这个_产品、产品_很棒

~~~

FastText 和 Word2Vec

  • FastText：字符级n-gram（⼦词）+ 词级n-gram（wordNgrams），灵活处理OOV和上下⽂。
  • Word2Vec：仅支持词级n-gram（需预处理，如New_York），无法处理OOV词。

这两者并不冲突，恰恰相反，子词和Ngrams结合使用：

model = fasttext.train_supervised(input='./a.txt', dim=10, minn=2, maxn=4, bucket=2000000, wordNgrams=2)

  • 问题：本地Redis服务未运行

🚀 Overview

This project implements a multi-model approach to text classification, combining traditional machine learning (Random Forest), efficient embeddings (FastText), transformer-based models (BERT), and large language models (LLM) to achieve state-of-the-art performance in text classification tasks, particularly sentiment analysis.

✨ Features

  • Four Model Integration: Seamlessly combines Random Forest, LLM, FastText, and BERT
  • Unified Interface: Consistent API across all models
  • Flexible Configuration: Easy model configuration through preset system
  • Comprehensive Evaluation: Detailed metrics and performance analysis
  • Caching System: Optimized performance with intelligent caching
  • Multi-Provider Support: Multiple LLM providers (DeepSeek, OpenAI, Local)
  • Device Optimization: Automatic device selection (GPU > MPS > CPU)

🏗️ Model Architecture

Model Stack

  1. Random Forest: Traditional ML with TF-IDF features
  1. FastText: Efficient text classification with subword embeddings
  1. BERT: Transformer-based contextual embeddings
  1. LLM: Large language model with prompt engineering

  • Best For: Large datasets, multilingual support

  • Features: Contextual embeddings, transfer learning
  • Best For: High accuracy requirements, complex language understanding

  • Type: Prompt-based classification
  • Features: Zero-shot capability, reasoning ability
  • Best For: Few-shot learning, complex reasoning tasks
  • Config: config/llm_config.py
