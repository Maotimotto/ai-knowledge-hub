Self-RAG 自适应检索增强生成

概述

Self-RAG 是由 Akari Asai 等人于 2023 年提出的框架（论文：Self-RAG: Learning to Retrieve, Generate, and Critique through Self-Reflection）。

核心思想：让 LLM 自主决定是否需要检索、何时检索、以及检索结果是否相关，而不是无条件地检索所有查询。

与传统 RAG 的关键区别：

  • 传统 RAG：始终检索 → 可能引入噪声
  • Self-RAG：按需检索 → 通过反思 token 自我评估

核心机制：反思 Token（Reflection Tokens）

Self-RAG 训练 LLM 在生成过程中输出特殊的反思 token，用于自我评估。

四类反思 Token

Token 类型 触发时机 可能取值 作用
[Retrieve] 每个段落开始前 {0, 1} 决定是否需要检索
[IsRel] 检索完成后 {0, 1} 判断检索文档是否与查询相关
[IsSup] 生成每个段落后 {0, 1, 2} 判断生成内容是否被检索文档支持
[IsUse] 生成每个段落后 {0, 1, 2} 判断生成内容的整体有用性

检索决策策略

何时应该检索？

Self-RAG 学会了在以下情况触发检索：

  1. 事实性问题：需要精确数据、日期、数字
  2. 专业知识查询：超出模型参数知识范围
  3. 多跳推理：需要多个信息源组合

何时跳过检索？

  1. 创意写作：不需要外部知识
  2. 通用常识：模型已有足够知识
  3. 格式化任务：翻译、摘要等

训练方法

阶段一：训练 Critic 模型

收集反思 token 标注数据，训练独立的 critic 模型：

python
# Critic 模型训练
class SelfRAGCritic:
    def __init__(self, base_model):
        self.model = base_model
        self.relevance_head = nn.Linear(hidden_dim, 2)   # IsRel
        self.support_head = nn.Linear(hidden_dim, 3)     # IsSup
        self.usefulness_head = nn.Linear(hidden_dim, 3)  # IsUse

    def assess_relevance(self, query, passage):
        """判断检索文档是否相关"""
        logits = self.relevance_head(
            self.model.encode(query, passage)
        )
        return torch.argmax(logits, dim=-1)  # 0 或 1

    def assess_support(self, claim, evidence):
        """判断生成内容是否被证据支持"""
        logits = self.support_head(
            self.model.encode(claim, evidence)
        )
        return torch.argmax(logits, dim=-1)  # 0, 1, 2

    def assess_usefulness(self, query, response):
        """判断回答的整体有用性"""
        logits = self.usefulness_head(
            self.model.encode(query, response)
        )
        return torch.argmax(logits, dim=-1)  # 0, 1, 2

# 训练数据格式
def format_training_sample(query, passages, response, critiques):
    """
    critiques 包含每个段落的反思 token 标注
    """
    text = f"### Query: {query}\n"

    for i, (passage, critique) in enumerate(zip(passages, critiques)):
        text += f"[Retrieve]{critique['retrieve']}\n"
        if critique['retrieve'] == 1:
            text += f"### Passage: {passage}\n"
            text += f"[IsRel]{critique['relevance']}\n"

        text += f"### Response Segment {i}: {response[i]}\n"
        text += f"[IsSup]{critique['support']}\n"
        text += f"[IsUse]{critique['usefulness']}\n"

    return text

推理时的解码策略

Self-RAG 在推理时使用 段落级束搜索（Segment-level Beam Search）：

python
class SelfRAGDecoder:
    def __init__(self, generator, critic, retriever, beam_width=3):
        self.generator = generator
        self.critic = critic
        self.retriever = retriever
        self.beam_width = beam_width

    def generate(self, query, max_segments=5):
        beams = [{"text": "", "score": 0.0}]

        for step in range(max_segments):
            candidates = []

            for beam in beams:
                # 决定是否检索
                retrieve_decision = self.critic.should_retrieve(
                    query, beam["text"]
                )

                if retrieve_decision == 1:
                    # 检索并评估相关性
                    passages = self.retriever.retrieve(query, top_k=5)
                    relevant = [
                        p for p in passages
                        if self.critic.assess_relevance(query, p) == 1
                    ]
                else:
                    relevant = []

                # 生成候选段落
                segments = self.generator.generate_segment(
                    query, beam["text"], relevant,
                    num_candidates=self.beam_width
                )

                # 用 critic 评分
                for seg in segments:
                    support_score = self.critic.assess_support(
                        seg, relevant
                    ) if relevant else 1
                    usefulness_score = self.critic.assess_usefulness(
                        query, beam["text"] + seg
                    )

                    # 综合评分
                    total_score = (
                        beam["score"]
                        + self.score_to_weight(support_score)
                        + self.score_to_weight(usefulness_score)
                    )

                    candidates.append({
                        "text": beam["text"] + seg,
                        "score": total_score
                    })

            # 保留 top-k beams
            beams = sorted(
                candidates, key=lambda x: x["score"],
                reverse=True
            )[:self.beam_width]

        return beams[0]["text"]

    def score_to_weight(self, score):
        """将反思 token 分数转换为权重"""
        mapping = {0: -0.5, 1: 0.3, 2: 0.5}
        return mapping.get(score, 0.0)

简化实现：基于提示的 Self-RAG

如果不想训练专用模型，可以用提示工程模拟：

python
SELF_RAG_PROMPT = """你是一个自我反思的AI助手。在回答问题时，请遵循以下步骤：

1. **检索决策**：首先判断是否需要检索外部信息。
   - 如果需要，说明你需要什么信息
   - 如果不需要，直接回答

2. **相关性评估**：（如果检索了）这些文档是否与问题相关？

3. **支持度检查**：你的回答是否被提供的证据支持？

4. **有用性评估**：你的回答是否真正解答了用户的问题？

请按以下格式回答：

[检索决策] 需要/不需要检索
[理由] 为什么需要/不需要
[检索查询] （如需要）具体的检索查询
[回答] 你的最终回答
[自评] 回答是否被证据支持，整体有用性如何
"""

class SimpleSelfRAG:
    def __init__(self, llm, retriever):
        self.llm = llm
        self.retriever = retriever

    def answer(self, query):
        # Step 1: 检索决策
        decision_prompt = f"""判断以下问题是否需要检索外部信息：
问题：{query}

仅回答：NEED_RETRIEVE 或 NO_RETRIEVE"""

        decision = self.llm.generate(decision_prompt).strip()

        if "NEED_RETRIEVE" in decision:
            # Step 2: 检索
            passages = self.retriever.retrieve(query, top_k=3)

            # Step 3: 相关性过滤
            relevant = []
            for p in passages:
                rel_prompt = f"判断文档是否与问题相关（YES/NO）：\n问题：{query}\n文档：{p}"
                if "YES" in self.llm.generate(rel_prompt):
                    relevant.append(p)

            # Step 4: 基于相关文档生成
            context = "\n\n".join(relevant) if relevant else "无相关文档"
            answer_prompt = f"""基于以下信息回答问题。如果信息不足以回答，请说明。

信息：{context}
问题：{query}"""
        else:
            answer_prompt = f"直接回答问题：{query}"

        answer = self.llm.generate(answer_prompt)

        # Step 5: 自评
        eval_prompt = f"""评估以下回答：
问题：{query}
回答：{answer}

回答是否准确且有用？简要说明。"""
        evaluation = self.llm.generate(eval_prompt)

        return {
            "answer": answer,
            "retrieved": "NEED_RETRIEVE" in decision,
            "num_relevant": len(relevant) if "NEED_RETRIEVE" in decision else 0,
            "self_evaluation": evaluation
        }

Corrective-RAG (CRAG) 纠错检索增强生成

概述

Corrective-RAG (CRAG) 由 Shi-Qi Yan 等人于 2024 年提出（论文：Corrective Retrieval Augmented Generation）。

核心思想：在 RAG 流程中加入一个轻量级检索评估器，对检索结果进行质量判断，并根据评估结果采取不同的纠正策略。

与 Self-RAG 的区别：

  • Self-RAG：LLM 自身反思，需要专用训练
  • CRAG：外部评估器打分，即插即用

核心架构

code
用户查询
   │
   ▼
┌──────────────┐
│  标准检索器    │ (如 BM25 + 向量检索)
└──────┬───────┘
       │ 检索文档
       ▼
┌──────────────┐
│  CRAG 评估器   │ ← 轻量级模型，对每个文档打分
└──────┬───────┘
       │
       ├──── Correct (置信度高) ────→ 知识精炼 → 生成
       │
       ├──── Incorrect (置信度低) ──→ Web 搜索补充 → 生成
       │
       └──── Ambiguous (模糊) ────→ 知识精炼 + Web 搜索 → 生成

三种响应策略

评估结果 置信度阈值 策略 说明
Correct > 0.8 知识精炼 检索质量好，提炼关键信息后生成
Incorrect < 0.3 Web 搜索 检索质量差，转向网络搜索补充
Ambiguous 0.3 ~ 0.8 两者结合 保留精炼结果 + Web 搜索补充

检索评估器设计

评估器模型

python
import torch
import torch.nn as nn
from transformers import AutoModel, AutoTokenizer

class RetrievalEvaluator(nn.Module):
    """
    轻量级检索质量评估器
    基于小型语言模型（如 DeBERTa-v3-small）微调
    """

    def __init__(self, model_name="microsoft/deberta-v3-small"):
        super().__init__()
        self.encoder = AutoModel.from_pretrained(model_name)
        self.classifier = nn.Linear(self.encoder.config.hidden_size, 1)
        self.tokenizer = AutoTokenizer.from_pretrained(model_name)

    def forward(self, query, document):
        """
        评估文档与查询的相关性
        返回 0~1 之间的置信度分数
        """
        inputs = self.tokenizer(
            query, document,
            return_tensors="pt",
            truncation=True,
            max_length=512,
            padding=True
        )

        outputs = self.encoder(**inputs)
        # 使用 [CLS] token 的表示
        cls_output = outputs.last_hidden_state[:, 0, :]
        score = torch.sigmoid(self.classifier(cls_output))
        return score

    def assess_documents(self, query, documents):
        """批量评估多个文档"""
        scores = []
        for doc in documents:
            score = self.forward(query, doc)
            scores.append(score.item())
        return scores

知识精炼算法

CRAG 的知识精炼是将检索文档分解为细粒度知识条目，过滤噪声：

python
class KnowledgeRefinement:
    """
    将检索文档分解为知识条目，过滤不相关部分
    """

    def __init__(self, llm, evaluator):
        self.llm = llm
        self.evaluator = evaluator

    def refine(self, query, documents, scores):
        """
        知识精炼流程：
        1. 文档分解为知识片段
        2. 过滤低相关性片段
        3. 重组为精炼知识
        """
        all_knowledge = []

        for doc, score in zip(documents, scores):
            # 步骤1：分解文档为知识片段
            segments = self.decompose_document(doc)

            # 步骤2：评估每个片段的相关性
            for seg in segments:
                seg_score = self.evaluator.assess_documents(
                    query, [seg]
                )[0]

                if seg_score > 0.5:  # 相关性阈值
                    all_knowledge.append({
                        "content": seg,
                        "relevance": seg_score,
                        "source": doc[:50]  # 来源标记
                    })

        # 步骤3：按相关性排序
        all_knowledge.sort(key=lambda x: x["relevance"], reverse=True)

        # 步骤4：重组为精炼知识文本
        refined = "\n\n".join(
            k["content"] for k in all_knowledge[:5]  # 保留 top-5
        )

        return refined

    def decompose_document(self, document):
        """
        将长文档分解为独立的知识片段
        """
        prompt = f"""请将以下文档分解为独立的知识片段。
每个片段应包含一个完整的信息点。

文档：
{document}

请以编号列表形式输出知识片段："""

        response = self.llm.generate(prompt)
        # 解析编号列表
        segments = [
            line.strip()
            for line in response.split("\n")
            if line.strip() and line.strip()[0].isdigit()
        ]
        return segments

class WebSearchFallback:
    """
    Web 搜索回退模块
    当检索评估结果为 Incorrect 或 Ambiguous 时触发
    """

    def __init__(self, search_api_key, llm):
        self.search_api = SearchAPI(search_api_key)
        self.llm = llm

    def search_and_refine(self, query, original_docs=None):
        """
        Web 搜索并精炼结果
        """
        # 步骤1：构造优化的搜索查询
        optimized_queries = self.optimize_queries(query)

        # 步骤2：执行搜索
        web_results = []
        for q in optimized_queries[:3]:  # 最多3个查询
            results = self.search_api.search(q, num_results=5)
            web_results.extend(results)

        # 步骤3：去重和过滤
        unique_results = self.deduplicate(web_results)

        # 步骤4：提取关键信息
        knowledge = self.extract_knowledge(query, unique_results)

        # 如果有原始文档且是 Ambiguous 模式，合并结果
        if original_docs:
            knowledge = self.merge_knowledge(original_docs, knowledge)

        return knowledge

    def optimize_queries(self, original_query):
        """
        将用户查询优化为更适合搜索引擎的查询
        """
        prompt = f"""将以下用户问题分解为2-3个适合搜索引擎的查询：
用户问题：{original_query}

要求：
1. 查询应简洁且包含关键词
2. 覆盖问题的不同方面
3. 每行一个查询"""

        response = self.llm.generate(prompt)
        return [q.strip() for q in response.split("\n") if q.strip()]

    def extract_knowledge(self, query, web_results):
        """
        从 Web 搜索结果中提取与查询相关的知识
        """
        context = "\n\n".join([
            f"[来源{i+1}] {r['title']}\n{r['snippet']}"
            for i, r in enumerate(web_results[:10])
        ])

        prompt = f"""从以下搜索结果中提取与问题相关的关键信息。
只提取直接回答问题的内容，忽略无关信息。

问题：{query}
搜索结果：
{context}

关键信息（按相关性排序）："""

        return self.llm.generate(prompt)

完整 CRAG Pipeline

class CRAGPipeline:
    """
    完整的 Corrective RAG 流程
    """

    def __init__(self, config):
        self.retriever = HybridRetriever(
            vector_store=config["vector_store"],
            bm25_index=config["bm25_index"]
        )
        self.evaluator = RetrievalEvaluator(
            model_name=config["evaluator_model"]
        )
        self.refiner = KnowledgeRefinement(
            llm=config["llm"],
            evaluator=self.evaluator
        )
        self.web_fallback = WebSearchFallback(
            search_api_key=config["search_api_key"],
            llm=config["llm"]
        )
        self.generator = config["llm"]

        # 阈值配置
        self.correct_threshold = config.get("correct_threshold", 0.8)
        self.incorrect_threshold = config.get("incorrect_threshold", 0.3)

    def answer(self, query):
        """
        完整的 CRAG 问答流程
        """
        # 步骤 1：标准检索
        documents = self.retriever.retrieve(query, top_k=5)

        # 步骤 2：评估检索质量
        scores = self.evaluator.assess_documents(query, documents)
        max_score = max(scores) if scores else 0
        avg_score = sum(scores) / len(scores) if scores else 0

        # 步骤 3：根据评估结果选择策略
        if max_score > self.correct_threshold:
            # Correct：知识精炼后生成
            strategy = "correct"
            refined_knowledge = self.refiner.refine(
                query, documents, scores
            )
            context = refined_knowledge

        elif max_score < self.incorrect_threshold:
            # Incorrect：转向 Web 搜索
            strategy = "incorrect"
            context = self.web_fallback.search_and_refine(query)

        else:
            # Ambiguous：精炼 + Web 搜索
            strategy = "ambiguous"
            refined = self.refiner.refine(query, documents, scores)
            web_knowledge = self.web_fallback.search_and_refine(
                query, original_docs=refined
            )
            context = f"【检索知识】\n{refined}\n\n【网络补充】\n{web_knowledge}"

        # 步骤 4：生成最终回答
        prompt = f"""基于以下信息回答用户问题。
如果信息不足，请明确说明你不确定的部分。

信息：
{context}

问题：{query}

回答："""

        answer = self.generator.generate(prompt)

        return {
            "answer": answer,
            "strategy": strategy,
            "retrieval_scores": scores,
            "max_confidence": max_score,
            "avg_confidence": avg_score,
            "num_documents": len(documents)
        }

        文档评分节点
        使用 LLM 对每个文档进行相关性判断
        """
        question = state["question"]
        documents = state["documents"]

        prompt = f"""你是一个文档相关性评估器。
判断以下文档是否与问题相关。

问题：{question}

文档：
{[doc.page_content[:200] for doc in documents]}

        grades = [g.strip() for g in response.content.split(",")]

        relevant_docs = [
            doc for doc, grade in zip(documents, grades)
            if "RELEVANT" in grade.upper()
        ]

        return {
            "documents": relevant_docs,
            "grade": "correct" if relevant_docs else "incorrect"
        }

    def decide_route(self, state):
        """根据评分决定路由"""
        if state["grade"] == "correct" and len(state["documents"]) > 0:
            return "generate"
        else:
            return "web_search"

    def web_search_node(self, state):
        """Web 搜索节点"""
        question = state["question"]
        results = self.web_search.invoke(question)
        return {
            "documents": [
                Document(page_content=r) for r in results
            ]
        }

    def generate_node(self, state):
        """生成节点"""
        question = state["question"]
        context = "\n\n".join(
            doc.page_content for doc in state["documents"]
        )

    多租户 RAG 管理器
    每个租户独立 Collection，共享底层基础设施

        self.vector_store = vector_store
        self.config = config
        self.tenant_registry = TenantRegistry()

        """确保租户的 Collection 存在"""
        collection_name = f"tenant_{tenant_id}_docs"

        if not await self.vector_store.has_collection(collection_name):
            await self.vector_store.create_collection(
                name=collection_name,
                dimension=self.config["embedding_dim"],
                metric="cosine",
                # 租户特定配置
                index_type="HNSW",
                index_params={
                    "M": 16,
                    "efConstruction": 200
                }
            )

        return collection_name

    async def ingest(self, tenant_id, documents):
        """租户文档入库"""
        collection = await self.ensure_tenant_collection(tenant_id)

        # 嵌入计算（共享嵌入服务）
        embeddings = await self.embedding_service.encode(
            [doc.content for doc in documents]
        )

        # 写入租户专属 Collection
        await self.vector_store.insert(
            collection=collection,
            vectors=embeddings,
            metadata=[{
                "tenant_id": tenant_id,
                "doc_id": doc.id,
                "created_at": doc.created_at,
                "source": doc.source
            } for doc in documents]
        )

    async def search(self, tenant_id, query, top_k=10):
        """租户隔离搜索"""
        collection = await self.ensure_tenant_collection(tenant_id)

        query_embedding = await self.embedding_service.encode([query])

        results = await self.vector_store.search(
            collection=collection,
            vector=query_embedding[0],
            top_k=top_k
        )

        return results

import hashlib
import numpy as np
from functools import lru_cache

class MultiLevelCache:
    """多级缓存系统"""

    def __init__(self, redis_client, embedding_service, config):
        self.redis = redis_client
        self.embedding_service = embedding_service

        # L1: 进程内 LRU 缓存
        self.l1_cache = {}
        self.l1_max_size = config.get("l1_size", 1000)

        # L3: 语义缓存相似度阈值
        self.semantic_threshold = config.get("semantic_threshold", 0.92)

        # 缓存 TTL
        self.ttl = config.get("cache_ttl", 3600)

    async def get(self, query):
        """多级缓存查询"""
        cache_key = self._generate_key(query)

        # L1: 进程缓存
        if cache_key in self.l1_cache:
            return self.l1_cache[cache_key]

        # L2: Redis 精确匹配
        cached = await self.redis.get(cache_key)
        if cached:
            self._update_l1(cache_key, cached)
            return cached

        # L3: 语义缓存（相似查询匹配）
        semantic_result = await self._semantic_lookup(query)
        if semantic_result:
            self._update_l1(cache_key, semantic_result)
            await self.redis.setex(cache_key, self.ttl, semantic_result)
            return semantic_result

        return None

    async def set(self, query, response):
        """写入缓存"""
        cache_key = self._generate_key(query)

        # 写入 L1
        self._update_l1(cache_key, response)

        # 写入 L2
        await self.redis.setex(cache_key, self.ttl, response)

        # 写入 L3 语义缓存
        await self._semantic_store(query, response)

    async def _semantic_lookup(self, query):
        """语义缓存查找"""
        query_embedding = await self.embedding_service.encode([query])

        # 在语义缓存中查找相似查询
        results = await self.semantic_index.search(
            vector=query_embedding[0],
            top_k=1,
            threshold=self.semantic_threshold
        )

        if results:
            return results[0]["response"]
        return None

    async def _semantic_store(self, query, response):
        """存储到语义缓存"""
        embedding = await self.embedding_service.encode([query])
        await self.semantic_index.insert(
            vector=embedding[0],
            metadata={"query": query, "response": response}
        )

    def _generate_key(self, query):
        """生成缓存键"""
        normalized = query.strip().lower()
        return f"rag:cache:{hashlib.sha256(normalized.encode()).hexdigest()}"

    def _update_l1(self, key, value):
        """更新 L1 缓存"""
        if len(self.l1_cache) >= self.l1_max_size:
            # 移除最早插入的条目
            oldest = next(iter(self.l1_cache))
            del self.l1_cache[oldest]
        self.l1_cache[key] = value

        self.vector_store = vector_store
        self.bm25_index = bm25_index
        self.alpha = config.get("alpha", 0.5)  # 融合权重

    async def search(self, query, top_k=20):
        """混合搜索"""
        # 并行执行两种搜索
        vector_results, bm25_results = await asyncio.gather(
            self._vector_search(query, top_k=top_k * 2),
            self._bm25_search(query, top_k=top_k * 2)
        )

        # 分数归一化
        vector_normalized = self._normalize_scores(vector_results)
        bm25_normalized = self._normalize_scores(bm25_results)

        # RRF (Reciprocal Rank Fusion) 融合
        fused = self._rrf_fusion(
            vector_normalized,
            bm25_normalized,
            k=60  # RRF 常数
        )

        return fused[:top_k]

    def _rrf_fusion(self, results_a, results_b, k=60):
        """
        Reciprocal Rank Fusion
        score(d) = Σ 1/(k + rank_i(d))
        """
        scores = {}

        for rank, result in enumerate(results_a):
            doc_id = result["id"]
            scores[doc_id] = scores.get(doc_id, 0) + 1 / (k + rank + 1)
            scores[doc_id + "_doc"] = result

        for rank, result in enumerate(results_b):
            doc_id = result["id"]
            scores[doc_id] = scores.get(doc_id, 0) + 1 / (k + rank + 1)
            scores[doc_id + "_doc"] = result

        # 按融合分数排序
        sorted_docs = sorted(
            [(doc_id, score) for doc_id, score in scores.items()
             if not doc_id.endswith("_doc")],
            key=lambda x: x[1],
            reverse=True
        )

        return [
            {**scores[doc_id + "_doc"], "fused_score": score}
            for doc_id, score in sorted_docs
        ]

    def _normalize_scores(self, results):
        """Min-Max 分数归一化"""
        if not results:
            return results

        scores = [r["score"] for r in results]
        min_s, max_s = min(scores), max(scores)
        range_s = max_s - min_s if max_s != min_s else 1

        for r in results:
            r["normalized_score"] = (r["score"] - min_s) / range_s

        return results

class RAGMetrics:
    """RAG 系统指标收集器"""

    def __init__(self, config):
        self.config = config
        self.metrics_store = MetricsStore()

    # ===== 检索质量指标 =====

    async def compute_retrieval_metrics(self, query_log):
        """
        计算检索质量指标
        需要标注数据或用户反馈
        """
        metrics = {
            "recall_at_5": [],
            "recall_at_10": [],
            "mrr": [],
            "ndcg_at_10": [],
            "hit_rate": []
        }

        for entry in query_log:
            query = entry["query"]
            retrieved = entry["retrieved_docs"]
            relevant = entry.get("relevant_docs", [])  # 标注数据

            if not relevant:
                continue

            # Recall@K
            for k in [5, 10]:
                retrieved_at_k = retrieved[:k]
                hits = len(set(retrieved_at_k) & set(relevant))
                metrics[f"recall_at_{k}"].append(
                    hits / len(relevant)
                )

            # MRR
            for rank, doc_id in enumerate(retrieved):
                if doc_id in relevant:
                    metrics["mrr"].append(1 / (rank + 1))
                    break
            else:
                metrics["mrr"].append(0)

        # 汇总
        return {
            k: sum(v) / len(v) if v else 0
            for k, v in metrics.items()
        }

    # ===== 生成质量指标 =====

    async def compute_generation_metrics(self, samples):
        """
        计算生成质量指标
        使用 LLM-as-judge 方法
        """
        results = {
            "faithfulness": [],
            "answer_relevance": [],
            "context_relevance": []
        }

        for sample in samples:
            # 使用 LLM 评估
            faithfulness = await self.evaluate_faithfulness(
                query=sample["query"],
                context=sample["context"],
                answer=sample["answer"]
            )
            results["faithfulness"].append(faithfulness)

            relevance = await self.evaluate_relevance(
                query=sample["query"],
                answer=sample["answer"]
            )
            results["answer_relevance"].append(relevance)

        return {
            k: sum(v) / len(v) if v else 0
            for k, v in results.items()
        }

上下文：
{context}

问题：{query}
回答：{answer}

评分标准：
- 1.0: 回答完全由上下文支持
- 0.5: 回答部分由上下文支持
- 0.0: 回答与上下文矛盾或无法验证

只输出一个 0 到 1 之间的数字：""".format(
            context=context, query=query, answer=answer

        except ValueError:

    async def compute_feedback_metrics(self, feedback_log):

        total = len(feedback_log)

PSI (Population Stability Index) 检测

import numpy as np
from scipy import stats

class DriftDetector:
    """漂移检测器"""

    def __init__(self, config):
        self.window_size = config.get("window_size", 1000)
        self.threshold = config.get("drift_threshold", 0.2)
        self.baseline = None

    def compute_psi(self, baseline, current, bins=10):
        """
        计算 Population Stability Index
        PSI < 0.1: 无显著变化
        PSI 0.1~0.2: 中等变化，需关注
        PSI > 0.2: 显著变化，需调查
        """
        # 分桶
        breakpoints = np.linspace(
            min(min(baseline), min(current)),
            max(max(baseline), max(current)),
            bins + 1
        )

        baseline_hist, _ = np.histogram(baseline, bins=breakpoints)
        current_hist, _ = np.histogram(current, bins=breakpoints)

        # 避免除零
        baseline_pct = (baseline_hist + 1) / (sum(baseline_hist) + bins)
        current_pct = (current_hist + 1) / (sum(current_hist) + bins)

        # PSI 公式
        psi = sum(
            (current_pct - baseline_pct) * np.log(current_pct / baseline_pct)
        )

        return psi

    def detect_score_drift(self, recent_scores):
        """
        检测检索分数漂移
        """
        if self.baseline is None:
            self.baseline = recent_scores
            return {"drift": False, "psi": 0}

        psi = self.compute_psi(self.baseline, recent_scores)

        return {
            "drift": psi > self.threshold,
            "psi": psi,
            "severity": "high" if psi > 0.25 else "medium" if psi > 0.15 else "low"
        }

    def detect_query_distribution_drift(self, baseline_queries, current_queries):
        """
        检测查询分布漂移
        使用嵌入向量的距离分布
        """
        # 计算查询嵌入的统计特征
        baseline_centroid = np.mean(baseline_queries, axis=0)
        current_centroid = np.mean(current_queries, axis=0)

        # 余弦相似度
        cosine_sim = np.dot(baseline_centroid, current_centroid) / (
            np.linalg.norm(baseline_centroid) * np.linalg.norm(current_centroid)
        )

        # 中心偏移距离
        centroid_drift = np.linalg.norm(baseline_centroid - current_centroid)

        return {
            "cosine_similarity": float(cosine_sim),
            "centroid_drift": float(centroid_drift),
            "drift": cosine_sim < 0.85  # 阈值
        }

class SlidingWindowMonitor:
    """
    滑动窗口监控
    持续监控指标，检测异常
    """

    def __init__(self, window_size=100, alert_threshold=2.0):
        self.window_size = window_size
        self.alert_threshold = alert_threshold  # 标准差倍数
        self.windows = {}

    def add_metric(self, metric_name, value):
        """添加新指标值"""
        if metric_name not in self.windows:
            self.windows[metric_name] = []

        self.windows[metric_name].append(value)

        # 保持窗口大小
        if len(self.windows[metric_name]) > self.window_size * 2:
            self.windows[metric_name] = self.windows[metric_name][-self.window_size * 2:]

    def check_anomaly(self, metric_name):
        """检查当前窗口是否存在异常"""
        values = self.windows.get(metric_name, [])
        if len(values) < self.window_size:
            return {"anomaly": False, "reason": "insufficient_data"}

        # 基线窗口 vs 当前窗口
        baseline = values[:self.window_size]
        current = values[self.window_size:]

        baseline_mean = np.mean(baseline)
        baseline_std = np.std(baseline)
        current_mean = np.mean(current)

        # Z-score 异常检测
        z_score = (current_mean - baseline_mean) / (baseline_std + 1e-8)

        return {
            "anomaly": abs(z_score) > self.alert_threshold,
            "z_score": float(z_score),
            "baseline_mean": float(baseline_mean),
            "current_mean": float(current_mean),
            "direction": "decrease" if z_score < 0 else "increase"
        }

    def get_trend(self, metric_name, recent_n=50):
        """获取指标趋势"""
        values = self.windows.get(metric_name, [])
        if len(values) < recent_n:
            return {"trend": "insufficient_data"}

        recent = values[-recent_n:]
        x = np.arange(len(recent))
        slope, _, r_value, _, _ = stats.linregress(x, recent)

        return {
            "slope": float(slope),
            "r_squared": float(r_value ** 2),
            "trend": "improving" if slope > 0.001 else "degrading" if slope < -0.001 else "stable"
        }

    def __init__(self, vector_store, config):
        self.vector_store = vector_store
        self.config = config

    async def check_freshness(self, documents):
        """
        检查文档新鲜度
        返回每个文档的新鲜度状态
        """
        results = []
        now = datetime.utcnow()

        for doc in documents:
            doc_type = doc.metadata.get("doc_type", "general")
            policy = self.FRESHNESS_POLICIES.get(
                doc_type,
                self.FRESHNESS_POLICIES["general"]
            )

            created_at = doc.metadata.get("created_at")
            if created_at:
                age_days = (now - created_at).days
                freshness_ratio = max(0, 1 - age_days / policy["ttl_days"])
            else:
                freshness_ratio = 0.5  # 未知日期，给予中等分数

            results.append({
                "document": doc,
                "freshness_ratio": freshness_ratio,
                "age_days": age_days if created_at else None,
                "is_fresh": freshness_ratio > 0.5,
                "doc_type": doc_type,
                "ttl_days": policy["ttl_days"]
            })

        return results

    async def apply_freshness_boost(self, query_results):
        """
        对检索结果应用新鲜度加权
        新鲜文档获得排名提升
        """
        freshness_checked = await self.check_freshness(query_results)

        for item in freshness_checked:
            original_score = item["document"].score
            freshness = item["freshness_ratio"]

            # 新鲜度加权公式：final = original * (0.7 + 0.3 * freshness)
            item["document"].score = original_score * (0.7 + 0.3 * freshness)
            item["adjusted_score"] = item["document"].score

        # 重新排序
        freshness_checked.sort(
            key=lambda x: x["adjusted_score"],
            reverse=True
        )

        return freshness_checked

    async def identify_stale_documents(self):
        """
        识别过期文档，供定期清理使用
        """
        all_docs = await self.vector_store.get_all_documents()
        freshness = await self.check_freshness(all_docs)

        stale = [f for f in freshness if not f["is_fresh"]]

        # 按过期程度排序
        stale.sort(key=lambda x: x["freshness_ratio"])

        return {
            "total_documents": len(all_docs),
            "stale_documents": len(stale),
            "stale_rate": len(stale) / len(all_docs) if all_docs else 0,
            "details": stale[:100]  # 前100个最过期的
        }

查询嵌入缓存

import hashlib
import numpy as np

class EmbeddingCache:
    """
    查询嵌入缓存
    避免重复计算相同查询的嵌入向量
    """

    def __init__(self, redis_client, embedding_service, config):
        self.redis = redis_client
        self.embedding_service = embedding_service
        self.ttl = config.get("ttl", 86400)  # 24小时
        self.prefix = "emb:cache:"

    async def encode(self, texts):
        """
        带缓存的嵌入计算
        命中率通常在 30-50%（相同查询反复出现）
        """
        results = {}
        uncached = {}
        cache_hits = 0

        # 1. 检查缓存
        for i, text in enumerate(texts):
            cache_key = self._get_key(text)
            cached = await self.redis.get(cache_key)

            if cached:
                results[i] = np.frombuffer(cached, dtype=np.float32)
                cache_hits += 1
            else:
                uncached[i] = text

        # 2. 计算未缓存的嵌入
        if uncached:
            indices = list(uncached.keys())
            new_texts = list(uncached.values())
            new_embeddings = await self.embedding_service.encode(new_texts)

            # 3. 写入缓存
            for idx, embedding in zip(indices, new_embeddings):
                results[idx] = embedding
                cache_key = self._get_key(texts[idx])
                await self.redis.setex(
                    cache_key,
                    self.ttl,
                    embedding.astype(np.float32).tobytes()
                )

        # 按原始顺序返回
        ordered = [results[i] for i in range(len(texts))]

        return ordered, {
            "total": len(texts),
            "cache_hits": cache_hits,
            "hit_rate": cache_hits / len(texts) if texts else 0
        }

    def _get_key(self, text):
        normalized = text.strip().lower()
        hash_val = hashlib.sha256(normalized.encode()).hexdigest()[:16]
        return f"{self.prefix}{hash_val}"

class DocumentEmbeddingDedup:
    """
    文档嵌入去重
    避免重复文档入库时重复计算嵌入
    """

    def __init__(self, content_hash_store):
        self.hash_store = content_hash_store

    async def compute_if_needed(self, documents):
        """
        只对新文档或变更文档计算嵌入
        """
        to_embed = []
        skipped = 0

        for doc in documents:
            content_hash = hashlib.sha256(
                doc.content.encode()
            ).hexdigest()

            existing = await self.hash_store.get(content_hash)

            if existing:
                # 内容未变，复用已有嵌入
                doc.embedding = existing["embedding"]
                skipped += 1
            else:
                to_embed.append(doc)

        if to_embed:
            embeddings = await self.embedding_service.encode(
                [d.content for d in to_embed]
            )

            for doc, emb in zip(to_embed, embeddings):
                doc.embedding = emb
                await self.hash_store.set(
                    hashlib.sha256(doc.content.encode()).hexdigest(),
                    {"embedding": emb, "doc_id": doc.id}
                )

        return {
            "total": len(documents),
            "computed": len(to_embed),
            "skipped": skipped,
            "cost_saved": skipped / len(documents) if documents else 0
        }

核心思想

用低成本方法做初筛，高成本方法做精排，减少昂贵调用次数。

class TieredRetriever:
    """
    分层检索器
    逐层缩小候选集，控制成本
    """

    def __init__(self, config):
        # Tier 1: 倒排索引（最快最便宜）
        self.bm25 = BM25Index(config["bm25_path"])

        # Tier 2: 向量检索
        self.vector_store = VectorStore(config["vector_config"])

        # Tier 3: 交叉编码器重排
        self.reranker = CrossEncoderReranker(config["reranker_model"])

        # 配置各层候选数
        self.tier1_k = config.get("tier1_k", 500)
        self.tier2_k = config.get("tier2_k", 50)
        self.tier3_k = config.get("tier3_k", 5)

    async def retrieve(self, query):
        """
        分层检索
        """
        # Tier 1: BM25 初筛
        tier1_results = await self.bm25.search(
            query, top_k=self.tier1_k
        )
        tier1_ids = [r["id"] for r in tier1_results]

        # Tier 2: 向量搜索（限定在 Tier 1 候选范围内）
        tier2_results = await self.vector_store.search(
            query,
            top_k=self.tier2_k,
            filter_ids=tier1_ids  # 只在 BM25 结果中搜索
        )

        # Tier 3: 交叉编码器重排（只处理 top 候选）
        tier3_results = await self.reranker.rerank(
            query,
            [r["content"] for r in tier2_results],
            top_k=self.tier3_k
        )

        return tier3_results

class QueryComplexityEstimator:
    """查询复杂度估算器"""

    def estimate(self, query):
        features = {
            "length": len(query),
            "has_multi_hop": "?" in query and "和" in query,
            "has_specific_entity": self._has_entity(query),
            "is_comparison": any(w in query for w in ["比较", "区别", "vs"])
        }

        if features["has_multi_hop"] or features["is_comparison"]:
            return "hard"
        elif features["length"] > 30 or features["has_specific_entity"]:
            return "medium"
        else:
            return "simple"

    def _has_entity(self, query):
        """简单的实体检测"""
        # 生产中使用 NER 模型
        import re
        return bool(re.search(r'[A-Z][a-z]+|[一-龥]{2,4}(?:公司|大学|产品)', query))

from sentence_transformers import CrossEncoder

class TieredReranker:
    """
    分级重排序器
    先用小模型粗排，必要时用大模型精排
    """

    def __init__(self, config):
        # 轻量级重排器（本地部署，近零成本）
        self.light_reranker = CrossEncoder(
            config.get("light_model", "cross-encoder/ms-marco-MiniLM-L-6-v2")
        )

        # 高精度重排器（API 调用，有成本）
        self.heavy_reranker = config.get("heavy_reranker")  # Cohere 或其他

        # 质量阈值：低于此值才触发大模型
        self.quality_threshold = config.get("quality_threshold", 0.6)

    async def rerank(self, query, candidates, top_k=5):
        """
        分级重排序
        """
        # Step 1: 小模型重排（几乎所有情况都够用）
        light_scores = self.light_reranker.predict(
            [(query, c["content"]) for c in candidates]
        )

        for candidate, score in zip(candidates, light_scores):
            candidate["rerank_score"] = float(score)

        # 按分数排序
        candidates.sort(key=lambda x: x["rerank_score"], reverse=True)
        light_top = candidates[:top_k]

        # Step 2: 检查是否需要大模型精排
        top_score = light_top[0]["rerank_score"] if light_top else 0

        if top_score < self.quality_threshold and self.heavy_reranker:
            # 分数不够高，用大模型确认
            heavy_results = await self.heavy_reranker.rerank(
                query,
                [c["content"] for c in light_top],
                top_k=top_k
            )
            return heavy_results

        return light_top

class RerankerDistillation:
    """
    用大模型重排序结果训练小模型
    降低长期推理成本
    """

    def __init__(self, teacher_model, student_model):
        self.teacher = teacher_model  # Cohere / GPT-4
        self.student = student_model  # MiniLM

    async def generate_training_data(self, queries, candidate_sets):
        """
        用教师模型生成训练数据
        """
        training_data = []

        for query, candidates in zip(queries, candidate_sets):
            # 教师模型打分
            teacher_scores = await self.teacher.rerank(
                query,
                [c["content"] for c in candidates]
            )

            for candidate, score in zip(candidates, teacher_scores):
                training_data.append({
                    "query": query,
                    "document": candidate["content"],
                    "teacher_score": score
                })

        return training_data

    def train_student(self, training_data, epochs=3):
        """
        训练学生模型
        使用 KL 散度损失
        """
        from torch.utils.data import DataLoader

        dataloader = DataLoader(training_data, batch_size=32, shuffle=True)
        optimizer = torch.optim.AdamW(self.student.parameters(), lr=2e-5)

        for epoch in range(epochs):
            total_loss = 0
            for batch in dataloader:
                # 学生模型预测
                student_scores = self.student.predict(
                    list(zip(batch["query"], batch["document"]))
                )

                # 教师模型分数作为标签
                teacher_scores = batch["teacher_score"]

                # KL 散度损失
                loss = torch.nn.KLDivLoss()(
                    torch.log_softmax(student_scores, dim=-1),
                    torch.softmax(teacher_scores, dim=-1)
                )

                loss.backward()
                optimizer.step()
                optimizer.zero_grad()
                total_loss += loss.item()

            print(f"Epoch {epoch+1}, Loss: {total_loss/len(dataloader):.4f}")

class PromptCompressor:
    """
    提示词压缩
    减少 token 数量，降低 LLM 成本
    """

    def __init__(self, llm):
        self.llm = llm

    async def compress_context(self, query, documents, target_ratio=0.5):
        """
        压缩检索上下文
        目标：保留关键信息，减少 token 数
        """
        original_tokens = sum(
            self._count_tokens(doc) for doc in documents
        )
        target_tokens = int(original_tokens * target_ratio)

        # 方法1：提取关键句子
        compressed = []
        for doc in documents:
            key_sentences = await self._extract_key_sentences(
                query, doc, max_sentences=3
            )
            compressed.extend(key_sentences)

        # 检查是否达标
        compressed_tokens = sum(self._count_tokens(s) for s in compressed)

        if compressed_tokens > target_tokens:
            # 进一步压缩：LLM 摘要
            compressed_text = "\n".join(compressed)
            summary = await self.llm.generate(
                f"将以下内容压缩到{target_tokens}个token以内，"
                f"保留与问题相关的关键信息：\n\n"
                f"问题：{query}\n内容：{compressed_text}"
            )
            return summary

        return "\n".join(compressed)

    async def _extract_key_sentences(self, query, document, max_sentences=3):
        """提取与查询最相关的句子"""
        sentences = document.split("。")
        # 简单实现：按关键词重叠排序
        query_words = set(query)
        scored = []
        for sent in sentences:
            overlap = len(set(sent) & query_words)
            scored.append((sent, overlap))

        scored.sort(key=lambda x: x[1], reverse=True)
        return [s[0] for s in scored[:max_sentences]]

    def _count_tokens(self, text):
        """估算 token 数"""
        return len(text) // 2  # 中文约2字符/token

class CostTracker:
    """成本跟踪器"""

    def __init__(self, redis_client):
        self.redis = redis_client

    async def track_request(self, request_id, costs):
        """
        跟踪单次请求成本
        """
        total = sum(costs.values())
        await self.redis.hset(
            f"cost:{request_id}",
            mapping={k: str(v) for k, v in costs.items()}
        )
        await self.redis.hset(
            f"cost:{request_id}",
            "total", str(total)
        )

        # 按小时聚合
        hour_key = datetime.utcnow().strftime("%Y%m%d%H")
        await self.redis.hincrbyfloat(
            f"cost:hourly:{hour_key}",
            "total", total
        )
        for k, v in costs.items():
            await self.redis.hincrbyfloat(
                f"cost:hourly:{hour_key}",
                k, v
            )

    async def get_daily_summary(self):
        """日成本汇总"""
        today = datetime.utcnow().strftime("%Y%m%d")
        summary = {}

        for hour in range(24):
            key = f"cost:hourly:{today}{hour:02d}"
            data = await self.redis.hgetall(key)
            if data:
                for k, v in data.items():
                    summary[k] = summary.get(k, 0) + float(v)

        return summary
