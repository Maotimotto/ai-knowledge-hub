金融智能咨询系统（多MCP协同Agent项目）

高级
来源: 知识星球/推荐的项目 | Agent开发面试高频考点

基于金融 SaaS 产品智能咨询工作台，搭建一套多 Agent 协作系统，通过 MCP 技术将金融文章风险扫描、投资建议、智能咨询、转人工等工具封装为独立服务，由 OpenAI Agents SDK 编排多智能体协作流转。

系统架构

用户输入 ↓ Switch Agent（业务分流） ├── Investment Agent ← 投资建议MCP │ ├── 股价查询 (cal_close_price_trend_tool) │ ├── 股价预测 (predict_future_7data_tool) │ └── 投资报告 (generation_stock_prediction_report_tool) ├── Article Check Agent ← 文章风险扫描MCP │ ├── 规范性审查 (basic_check_tool) │ ├── 专业性审查 (professional_check_tool) │ ├── 审查报告 (produce_check_result_report_tool) │ └── 文章改进 (produce_refine_report_tool) ├── Consult Agent ← 金融咨询MCP │ ├── 本地知识库RAG (invest_policy_consult_tool) │ └── 网络检索 (finance_news_search_consult_tool) └── Turn Human Agent ← 转人工MCP └── 转人工 (turn_human_tool)

3. Instruction 流程编排

每个 Agent 的 instruction 用文字化描述子业务流程：

1.询问用户需要预测或查询的股票名称 1a) 如果想预测未来走势 → 调用 predict_future_7data_tool 1b) 如果想查询当前收盘价 → 调用 cal_close_price_trend_tool 1c) 如果想生成报告 → 继续下一步 2. 生成报告： 2a) 先调用 predict_future_7data_tool 2b) 再调用 cal_close_price_trend_tool 2c) 最后调用 generation_stock_prediction_report_tool 3. 确认用户是否有其他问题，无则移交回 Switch Agent

5. 股价预测算法（EMA 指数移动平均）

Python
def exponential_moving_average(series, alpha, forecast_periods=1):
    ema = series.ewm(alpha=alpha, adjust=False).mean()
    last_ema = ema[-1]
    forecast_values = np.full(forecast_periods, last_ema)
    future_dates = pd.date_range(start=series.index[-1],
                                  periods=forecast_periods + 1, ...)
    forecast_series = pd.Series(forecast_values, index=future_dates)
    return pd.concat([ema, forecast_series])

面试高频问题

Q: 为什么选用 Agents SDK？
擅长高度自由的交互式对话业务，子流程不过于复杂但主场景需频繁切换。代码量少，不易出 Bug，和 DeepSeek 模型是绝配。
Q: 还有哪些框架能实现？
LangGraph（supervisor 架构）、AutoGen（中心化调度）、Google ADK 等。
Q: 复杂子流程怎么办？
将大过程分拆到多个 Agent，每个子 Agent 管一部分流程，再在 Agent 间建立 handoff。

01

从 0 到 1 打造多 MCP 协同智能体系统（面试问答）

高级
来源: 知识星球 | 覆盖80% Agent开发面试核心考点

本文档是 Agent 开发知识体系中的面试备战指南，汇总了多 MCP 协同智能体系统的高频面试问题和标准答案。

面试高频问答

1. 项目难点或挑战？

  1. 多个 MCP 工具同时连接，需要保持所有 MCP Server 与 Client 在一个对话 session 中，否则会引起连接中断
  2. AgentsSDK 多智能体框架要实现多个 Agent 协作共同办理业务，需要建立智能体之间两两移交的策略
  3. 单个智能体内部子业务流程需要在智能体上做好 instruction 的流程编排 prompt 定义

2. 为什么选用 AgentsSDK 框架？

  • 善于处理高度自由的交互式用户对话业务办理
  • 擅长单个智能体内子流程不复杂、但主场景需要频繁切换的场景
  • 代码量相对其他框架较少，不容易出 bug，和 DeepSeek 模型是绝配

3. 其他可选多智能体框架？

  • LangGraph：使用 supervisor 作为中心调度者，下游监管多个智能体
  • AutoGen：中心化架构调度智能体
  • Google ADK：Google 的 Agent Development Kit

4. 子业务流程连续对话如何实现？

通过智能体上定义 instruction（指导智能体办理逻辑的 prompt），对流程先后顺序进行文字化描述。这类高度自由化的 Agent 系统不适合子业务流程特别复杂（如 10+ 步骤）的场景。

5. 多智能体协作如何实现？

通过智能体之间的 handoff 逻辑：配置智能体之间两两都能实现 handoff，让大模型在 Agent1 中办理业务得到中间产物后，转到 Agent2 中继续拿着中间产物进行对话交付和工具调用。

6. MCP 是什么？

MCP（Model Context Protocol）是一个标准的模型上下文协议，就像给 AI 大模型装了一个"万能接口"：

  • 像 USB-C 接口一样，提供标准化方法将 AI 模型连接到各种数据源和工具
  • 旨在替换碎片化的 Agent 代码集成，使 AI 系统更可靠
  • 可以在不同应用和服务之间保持上下文，增强自主执行任务的能力

7. MCP 三类传输协议对比

协议特点适用场景局限
stdio客户端将 MCP Server 作为子进程启动，通过 stdin/stdout 通信命令行工具、本地集成只能在本地服务器使用
SSE + HTTP服务器独立运行，通过 SSE 连接接收消息服务器到客户端流式传输不支持恢复连接
Streamable HTTP客户端用 POST/GET 发请求，可选升级为 SSE 流统一 message 端点目前最新最优模式

8. 如何保持多个 MCP 工具在同一会话中使用？

构建一个统一的上下文会话管理器，不能单纯将每个 MCP Server 和 Client 单独连接。在这个统一的 session 下，连接所有 MCP 服务器后，将所有工具取出，走正常的 function calling 流程。

9. MCP 工具的并行调用和串行调用？

  • 串行调用：LLM 自主规划分先后调用工具。如：先调用规范性审查工具，再调用另一个工具写审查报告
  • 并行调用：LLM 自主规划在同一时间多次/同步调用工具。如：同时调用规范性审查工具和专业性审查工具

10. 历史消息如何管理？

  • 需要存储到数据库中，不能按框架默认方式存到本地文件
  • 会话量通常非常大，存在单台服务器上会造成无限扩容
  • 只需存储 AI 回复和用户问题，中间的工具调用日志无需存储

11. 如何实现分业务人工转接？

通过 Function Calling 的槽位提取功能：将业务场景分为'金融咨询'、'股票预测'、'文章审查'、'通用业务'。定义"转接场景抽取工具"，根据抽取到的业务场景手动调用下游转接 API。

12. 系统的劣势和缺点？

当需要融入特别复杂的业务流程时可能受到挑战。解决措施：将大过程分拆到多个智能体实现，每个子智能体分管一部分流程，再在多个智能体之间建立移交。

13. Prompt 输出格式稳定性如何控制？

通过指定输出模板 + 写 Few-shot Prompt 的方式引导模型按照预定模式输出。

14. 如何保证 QPS？

  • 所有服务通过异步（非阻塞式方法）编写，天然不怕同步阻塞
  • 使用 FastAPI 的多线程启动服务，进一步保障高可用性
  • 压测结果：能承受 560+ 并发

OpenAI Agent SDK 开发指南

进阶
来源: 知识星球 | Agent开发的速查手册

OpenAI Agents SDK 是 OpenAI 于 2025 年发布的事件驱动多智能体框架，特点是代码量少、易上手，特别适合处理高度自由的交互式对话业务。

注意事项

  • DeepSeek 模型必须是官网模型（其他接入平台暂不支持 Function Calling）
  • 每次运行产生一系列事件，通过 result.new_items 查看
  • 智能体转交通过内部执行 transfer_xxx_agent 的 Function Calling 实现

1. Agent 定义与调用

Python
from agents import Agent, Runner, OpenAIChatCompletionsModel, set_default_openai_client
from openai import AsyncOpenAI

# 配置 DeepSeek 模型
external_client = AsyncOpenAI(
    base_url="https://api.deepseek.com",
    api_key="sk-xxx")
set_default_openai_client(external_client)
deepseek_model = OpenAIChatCompletionsModel(
    model="deepseek-chat", openai_client=external_client)

# 创建 Agent
consult_agent = Agent(
    name="consult agent",
    instructions="你是一个只能回答医疗领域的智能体",
    model=deepseek_model)

# 运行
result = await Runner.run(starting_agent=consult_agent, 
                           input="美国次贷危机发生在哪一年？")
print(result.final_output)  # 最终输出
print(result.new_items)     # 全部事件列表

3. 工具调用（Function Tool）

from agents import function_tool

@function_tool
async def predict_future_7data_tool(stock_name: str) -> str:
    """
    输入股票名称，返回未来涨跌趋势
    :param stock_name: 股票名称，如上证指数、中国石油
    :return: 涨跌趋势描述
    """
    return predict_future_7data(stock_name)

# Agent 绑定工具
stock_agent = Agent(
    name="收盘价预测Agent",
    instructions="你能预测股票未来的收盘价",
    tools=[predict_future_7data_tool],
    model=deepseek_model)

result = await Runner.run(stock_agent, input="上证指数未来收盘价？")

5. 集成 MCP Server

Python
from agents.mcp import MCPServerSse
from contextlib import AsyncExitStack

async def run_with_mcp():
    async with AsyncExitStack() as stack:
        # 创建 MCP Server 实例
        server = MCPServerSse(
            name="stock Server",
            cache_tools_list=True,
            params={"url": "http://server:7336/sse"})
        entered_server = await stack.enter_async_context(server)

        # Agent 绑定多个 MCP Server
        agent = Agent(
            name="Assistant",
            instructions="你是股票心理按摩师",
            mcp_servers=[entered_server],
            model=deepseek_model)
        
        result = await Runner.run(agent, input="查询上证指数趋势")
        print(result.final_output)

6. 事件循环机制

Runner.run 是一个事件循环，不停执行直到 max_turns 或完成任务：

# 事件类型
result.new_items  # 包含：
# - MessageOutputItem: 文本输出
# - HandoffOutputItem: Agent 转交
# - ToolCallItem: 工具调用
# - ToolCallOutputItem: 工具返回

关键 API 速查

API说明
Agent(name, instructions, tools, model)定义智能体
Runner.run(starting_agent, input)运行智能体
result.final_output最终输出
result.new_items所有事件
result.to_input_list()转为多轮对话输入
@function_tool定义工具装饰器
handoffs=[agent1, agent2]配置转交列表
MCPServerSse(params={"url":...})SSE MCP 服务
