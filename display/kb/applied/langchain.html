概览

LangChain学习路线

LangChain之于LLMs，类似Spring之于Java。2022年10月由Harrison Chase发起，是最早的大模型应用开发框架。

六大核心模块：Model I/O - Chains - Memory - Agents - Retrieval - Callbacks

生态体系：LangChain(核心) + LangGraph(图编排) + LangSmith(监控) + LangServe(部署)

学习路径：概述 -> Model I/O -> Chains -> Memory -> Tools -> Agents -> Retrieval

第01章 概述

LangChain使用概述

尚硅谷LangChain课件 · 入门 · 1169行

LangChain入门总览：什么是LangChain、为什么需要它、在大模型应用开发生态中的位置。涵盖RAG架构、Agent架构、四大应用场景（纯Prompt/Agent+FC/RAG/微调）的选型决策。

核心要点：LangChain != LLM，而是LLM的应用开发框架。提供Prompt构建、LLM接入、记忆管理、工具调用、RAG、智能体开发等模块。

第02章 Model I/O

LangChain使用之Model I/O

尚硅谷LangChain课件 · 入门 · 3936行

Model I/O是与LLM交互的核心组件：Format(提示模板) -> Predict(模型调用) -> Parse(输出解析)。涵盖LLM vs ChatModel对比、三种模型获取方式（硬编码/环境变量/.env文件）、OpenAI/百度千帆/阿里百炼/智谱GLM/硅基流动等平台接入、PromptTemplate/ChatPromptTemplate使用、流式输出与批量调用。

第03章 Chains

LangChain使用之Chains

尚硅谷LangChain课件 · 中等 · 1193行

Chain是将Prompt + Model + Memory + Tools串联成可复用工作流的核心机制。LCEL管道符语法（prompt | model | parser）、LLMChain、SimpleSequentialChain、SequentialChain、RouterChain、SQL查询链、文档处理链。

第04章 Memory

LangChain使用之Memory

尚硅谷LangChain课件 · 中等 · 1171行

LLM本身无状态，Memory模块负责存储和管理多轮对话历史。ChatMessageHistory、ConversationBufferMemory、ConversationSummaryMemory、ConversationSummaryBufferMemory、VectorStoreRetrieverMemory等记忆类型。

第05章 Tools

LangChain使用之Tools

尚硅谷LangChain课件 · 中等 · 371行

Tools让LLM从"纸上谈兵"走向"改变世界"。通过搜索、计算、数据库查询等工具，Agent才能具备真正的行动能力。@tool装饰器自定义工具、StructuredTool.from_function、工具属性（name/description/args_schema/return_direct）。

第06章 Agents

LangChain使用之Agents

尚硅谷LangChain课件 · 进阶 · 1319行

Agent是AI应用的"终极形态" — 不像Chain那样硬编码流程，而是用LLM作为推理引擎，动态决定任务拆解、工具选择、执行顺序。ReAct推理循环、AgentExecutor、OpenAI Functions Agent、create_openai_tools_agent。

第07章 Retrieval

LangChain使用之Retrieval

尚硅谷LangChain课件 · 进阶 · 3020行

RAG检索增强生成的完整流程：文档加载(Document Loaders) -> 文本切分(Text Splitters) -> 向量化(Embeddings) -> 向量存储(Vector Stores) -> 检索(Retriever) -> 重排序(Reranker)。解决LLM幻觉问题的核心技术。
