覆盖JOIN、子查询、聚合、窗口函数等核心操作的50道经典SQL练习题，使用学生-课程-教师-成绩四表模型。

核心知识点：

  • 多表联查：INNER JOIN / LEFT JOIN / RIGHT JOIN
  • 子查询：IN / EXISTS / NOT EXISTS
  • 聚合函数：COUNT / SUM / AVG / MAX / MIN + HAVING
  • 窗口函数：RANK() / DENSE_RANK() / ROW_NUMBER()
  • 条件表达式：CASE WHEN / IF

表结构：Student(学生) / Course(课程) / Teacher(教师) / Score(成绩)

面试价值：SQL是AI项目的数据基础设施 — RAG系统需要从数据库检索知识、Agent需要Text-to-SQL查询业务数据、投顾助手需要实时读取行情数据。
