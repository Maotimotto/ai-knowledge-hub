Docker简介

Docker简介

Docker/Docker简介 · 难度 2/5

Docker可以理解为一个应用商店，允许你：用的时候让应用跑起来，不用的时候彻底关闭，同时可以下载同一应用的不同版本来使用，不会出现兼容性问题，各自有各自的房间，是隔离的。

核心概念：镜像(Image)=安装包，容器(Container)=运行实例，Dockerfile=安装说明书

MySQL容器化部署

Docker部署MySQL

Docker/ · 540行 · 难度 2/5

数据库容器化完整指南：镜像拉取、容器创建、数据持久化、远程连接配置、备份恢复、常见问题排查。

# 生产环境级启动命令
docker run --name mysql8 --restart=always \
  -e MYSQL_ROOT_PASSWORD=123456 \
  -p 3306:3306 \
  -v mysql-data:/var/lib/mysql \
  -d mysql:8.0.36 \
  --character-set-server=utf8mb4
