1. 深度学习基础面试题

1.1 数据归一化

什么是数据归一化？

归一化是将数据处理后限制在一定范围内，保证模型运行时收敛加快。

为什么要归一化？

  • 取消量纲差异，使梯度始终朝最小值方向前进
  • 加速收敛，少走弯路

    • 哪些模型不需要归一化？

  • 概率模型（决策树、随机森林）不关心变量值，关心分布
  • 最优化问题（SVM、LR、KNN、KMeans）需要归一化

    • 1.2 LSTM vs RNN

    LSTM有进有出，cell information通过input gate控制后叠加；RNN是叠乘，因此LSTM可以防止梯度消失或爆炸。

    1.3 激活函数对比

    函数 优点 缺点
    Sigmoid 输出有界，可做概率 梯度消失，计算量大，非零中心
    Tanh 零中心输出 梯度消失
    ReLU 计算简单，稀疏性，无梯度消失 神经元死亡（负区间输出为0）
    Leaky ReLU 解决死亡问题 需要调参
    GELU 平滑非线性 计算稍复杂
    Maxout ReLU泛化版本 参数翻倍

    1.4 为什么引入非线性激活函数？

  • 线性激活函数下，多层网络等价于一层网络：f(W1·f(W2·x)) = W1W2·x = W·x
  • 非线性变换对空间进行变换，使线性不可解的问题变得可解

    • 1.5 ReLU优于Sigmoid/Tanh的原因

  • 计算效率：ReLU只需max(0,x)，Sigmoid需要指数运算
  • 无饱和倾向：Sigmoid在饱和区导数趋于0，ReLU不会
  • 稀疏性：ReLU使部分神经元输出为0，减少过拟合

    • 1.6 LSTM中为什么同时使用Sigmoid和Tanh？

  • Sigmoid用在各种gate上，产生0~1之间的值（记住或忘掉）
  • Tanh用在状态和输出上，是对数据的处理

    • 1.7 解决RNN梯度爆炸和弥散

    梯度爆炸：当梯度大于阈值时截断为较小值

    梯度弥散：

  • 将随机初始化W(hh)改为有关联的矩阵初始化
  • 使用ReLU代替Sigmoid

    • 1.8 不适合深度学习的数据集

  • 数据集太小，样本不足
  • 数据集没有局部相关特性（如健康数据的特征打乱不影响结果）

    • 1.9 梯度消失与梯度膨胀

    梯度消失：每层偏导乘权重都小于1，多层传播后趋于0

  • 解决：ReLU激活函数、Batch Normalization

    • 梯度膨胀：每层偏导乘权重大于1，多层传播后趋于无穷

  • 解决：激活函数、Batch Normalization

    • 1.10 常见优化算法

    算法 特点
    GD 最基础，使用全部数据
    SGD 使用单个/小批样本，更快但噪声多
    Momentum 引入动量项加速收敛
    AdaGrad 自适应学习率，可能过早衰减
    RMSProp 改进AdaGrad，引入衰减系数
    Adam 结合Momentum和RMSProp，最常用

    1.11 Batch Size对训练的影响

    过小：梯度估计不稳定，训练时间长

    过大：内存消耗大，可能收敛到次优解

    处理方法：调整batch size、正则化、增加数据量、早停策略

    2. 计算机视觉面试题

    2.1 CNN的组成

    典型结构：INPUT → CONV → RELU → POOL → FC

    层类型 是否有参数 是否有超参数
    卷积层 ✓ ✓
    RELU层 ✗ ✗
    Pooling层 ✗ ✓
    全连接层 ✓ ✓

    2.2 1×1卷积核的作用

  • 实现跨通道的交互和信息整合
  • 进行通道数的降维和升维
  • 大幅减少参数量（如从589,824降到69,632）

    • 2.3 扩张卷积（Dilated Convolution）

  • 引入扩张率（dilation rate），定义卷积核值之间的间隔
  • 3×3卷积核扩张率为2时，感受野与5×5相同，但只用9个参数
  • 在实时分割领域特别受欢迎

    • 2.4 空间金字塔池化（SPP）

  • 用不同大小池化窗口（1×1, 2×2, 4×4）作用于特征
  • 将不同大小图像转化成相同维度特征
  • 让CNN处理任意尺度的输入

    • 2.5 CNN局部连接与权值共享

    局部连接：每个神经元仅与输入的一块区域连接（感受野），大幅减少参数

    权值共享：同一卷积核在不同位置共享参数，进一步减少参数量

    2.6 目标检测

    Two-stage方法：R-CNN → Fast R-CNN → Faster R-CNN

  • 先生成候选区域，再分类

    • One-stage方法：YOLO、SSD

  • 直接预测类别和位置

    • 关键概念：

  • IOU：预测框与真实框的交并比
  • NMS：非极大值抑制，去除冗余框
  • RPN：区域建议网络
  • ROI Pooling：将不同大小区域映射为固定大小

    • 2.7 语义分割

    FCN（全卷积网络）：

  • 将全连接层转换为卷积层
  • 用反卷积层上采样到输入尺寸
  • 实现像素级分类

    • U-Net：编码器-解码器结构，跳跃连接

    DeepLab系列：使用空洞卷积和CRF

    2.8 CNN参数设置

    参数 建议
    学习率 初始0.1，逐步除以2或5
    Batch Size 根据数据集大小调整
    权重衰减 一般0.005
    Epoch 训练至收敛

    2.9 Inception系列演进

    版本 主要改进
    V1 多尺度融合（1×1, 3×3, 5×5卷积+3×3池化）
    V2 卷积分解，两个3×3代替5×5
    V3 继续分解，1×n + n×1代替n×n
    V4 结合ResNet残差思想
