地址对齐 (NER 序列标注)

难度 3/5 NER 是 NLP 基础任务，面试常考

基于 BERT 的地址序列标注系统，将非结构化地址文本解析为省市区等结构化数据。本质是 NER 任务，用 BERT + 分类头逐 token 标注。

技术要点

  • BIES 标注体系：Begin/Inside/End/Single 四标签细化边界
  • 15+ 标签类型：prov(省)/city(市)/district(区)/road(街道)/houseno(门牌号) 等
  • 子词对齐：BERT tokenizer 的 word_ids 对齐策略，一个汉字可能被拆成多个 token
  • FastAPI 部署：提供 Web 服务接口
BERT PyTorch 序列标注 FastAPI TensorBoard

智选新闻 (分类 + 摘要)

难度 进阶 PyTorch + 束搜索 + FastAPI

基于 BART 预训练模型的新闻分类与摘要系统。涵盖数据预处理、模型搭建（束搜索）、训练、预测和 API 服务部署全流程。

应用场景

  • 新闻推荐系统：基于用户行为推荐符合用户喜好的新闻类型
  • 新闻聚合网站：将不同新闻内容按照类别整理展示
  • 媒体编辑：对大量新闻稿做分类处理
  • 搜索引擎优化：根据分类结果快速定位相关内容

束搜索（Beam Search）

一种启发式搜索算法，在序列生成中平衡搜索效率和结果质量。贪心搜索每次只选概率最高的词，容易陷入局部最优；束搜索维护 k 个最优候选序列（beam），综合考虑全局概率。

难度 4/5 电商 AI 是大模型落地重要场景

构建电商领域知识图谱并搭建智能电商客服系统。核心技术架构分为数据源、知识图谱(Neo4j)、对话处理(意图识别+实体抽取)、应用层四个模块。

  2. 意图识别：BERT 分类模型，14种意图查询
  3. 实体抽取：UIE 模型，抽取商品属性
  4. 图谱查询：Neo4j Cypher 查询

Neo4j 图数据库

难度 3/5 知识图谱项目必备技能

Neo4j 是目前最流行的图数据库，采用原生图存储与查询引擎。本教程涵盖安装部署、Cypher 语言、高级查询和 Python 驱动等完整技能栈。

核心概念

概念说明
节点 (Node)代表实体对象，拥有标签(Label)和属性(Properties)
关系 (Relationship)连接两个节点的有向连接，拥有类型(Type)和属性
路径 (Path)由节点和关系连接构成的结构

Cypher 基础操作

-- 创建节点
CREATE (n:Person {name: '王宝强', gender: '男'})

-- 创建关系
MATCH (n1:Person {name: '王宝强'}), (n2:Movie {title: '唐探1900'})
CREATE (n1)-[:ACTED_IN {role: '阿鬼'}]->(n2)

-- 查询路径
MATCH path = (n1:Person)-[r:ACTED_IN]->(n2:Movie)
RETURN path

-- 合并操作（Match + Create）
MERGE (n:Movie {title: '唐探1900'})
ON CREATE SET n.create_time = datetime()

Python 驱动

智图寻宝 (图像识别)

难度 中级 深度学习图像处理系统

基于深度学习的智能商品识别系统，集成了图像相似性搜索、图像去噪和商品分类三大核心功能。

核心功能

模块技术功能
图像去噪自编码器 (Autoencoder)学习图像特征重建无噪声图像
商品分类CNN 分类模型识别五类商品
相似图片检索自编码器 + KNN提取特征向量，KNN 检索最近似图片

自编码器架构

  • 编码器：Conv2d + ReLU + MaxPool2d，将图像压缩为低维特征
  • 解码器：ConvTranspose2d + ReLU，从低维特征重建图像
  • 损失函数：均方误差(MSE)，最小化重建误差
PyTorch Flask 自编码器 CNN KNN PIL
