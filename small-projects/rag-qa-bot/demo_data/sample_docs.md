# Document 1: Transformer Architecture

The Transformer architecture, introduced in the 2017 paper "Attention Is All You Need," revolutionized natural language processing. Unlike recurrent neural networks (RNNs), Transformers process entire sequences in parallel using self-attention mechanisms. Each token attends to every other token in the sequence, capturing long-range dependencies efficiently. The architecture consists of an encoder-decoder structure, where the encoder maps input sequences to continuous representations, and the decoder generates output sequences autoregressively. Key components include multi-head attention, positional encoding, and feed-forward networks. This design enables massive parallelization during training, making it possible to scale to billions of parameters. Modern large language models like GPT, LLaMA, and Mistral are all based on the Transformer architecture, typically using decoder-only variants.

# Document 2: Retrieval-Augmented Generation (RAG)

Retrieval-Augmented Generation (RAG) is a technique that enhances large language models by incorporating external knowledge retrieval at inference time. Instead of relying solely on parametric knowledge stored in model weights, RAG systems retrieve relevant documents from a knowledge base and provide them as context to the LLM. A typical RAG pipeline involves three stages: indexing (chunking documents and creating vector embeddings), retrieval (finding the most relevant chunks using similarity search), and generation (producing answers conditioned on retrieved context). RAG addresses key LLM limitations including knowledge cutoffs, hallucination, and lack of domain-specific information. Popular frameworks for building RAG systems include LangChain, LlamaIndex, and Haystack. Vector databases like Pinecone, Weaviate, and ChromaDB are commonly used for efficient similarity search over document embeddings.

# Document 3: Reinforcement Learning from Human Feedback (RLHF)

Reinforcement Learning from Human Feedback (RLHF) is a training methodology used to align language models with human preferences. The process involves three key steps. First, a language model is pre-trained on large text corpora using standard supervised learning. Second, human annotators rank model outputs for the same prompt, and these rankings are used to train a reward model that predicts human preferences. Third, the original language model is fine-tuned using reinforcement learning (typically Proximal Policy Optimization or PPO) to maximize the reward model's score while staying close to the original model through a KL divergence penalty. RLHF has been instrumental in making models like ChatGPT, Claude, and Llama-Chat more helpful, harmless, and honest. Variants like DPO (Direct Preference Optimization) and RLAIF (RL from AI Feedback) have emerged as more efficient alternatives.
