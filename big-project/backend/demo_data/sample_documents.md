# AI内容创作平台使用指南

## 1. 视频生成功能

AI视频生成是本平台的核心功能之一。用户只需输入文字描述（prompt），系统会自动选择合适的风格模板，生成高质量的短视频内容。

支持的风格包括：
- **电影风格（cinematic）**：适合品牌宣传片
- **动漫风格（anime）**：适合年轻用户群体
- **写实风格（realistic）**：适合产品展示
- **卡通风格（cartoon）**：适合儿童教育内容

生成时间通常为5-15分钟，取决于视频长度和分辨率。

## 2. 评论智能分析系统

评论分析模块基于NLP技术，能够自动识别评论的情感倾向（正面/负面/中性），并计算置信度分数。

核心能力包括：
- 情感分析：准确率达95%以上
- 关键词提取：自动提取评论中的核心词汇
- 毒性检测：识别恶意评论和垃圾信息
- 自动回复：根据评论内容生成合适的回复建议

支持的平台：微博、抖音、小红书、微信公众号。

## 3. RAG知识库问答

RAG（Retrieval-Augmented Generation）知识库是平台的智能问答系统。用户可以将文档导入知识库，之后通过自然语言提问获取精准答案。

工作流程：
1. 文档导入：支持Markdown、PDF、Word等格式
2. 文档分块：自动将长文档切分为语义完整的段落
3. 向量索引：使用embedding模型将文本转换为向量
4. 语义检索：根据问题检索最相关的文档片段
5. 答案生成：结合检索结果和大语言模型生成回答
